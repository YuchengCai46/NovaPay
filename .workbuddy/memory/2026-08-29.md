## Content-Type 修复 (2026-08-29 10:39)

### 问题
用户反馈：访问网站时浏览器自动下载一个文件而非显示页面。

### 根因
`serveFrontend()` 中当 URL 为 `/` 时，`path = ''`（空字符串），`ext = ''`，contentType 映射表找不到 `.html` 键，默认走了 `application/octet-stream`，浏览器把 HTML 当二进制下载。

### 修复
在 worker.js `serveFrontend()` 函数中加入：
```js
const resolvedPath = path || 'index.html';
const ext = resolvedPath.slice(resolvedPath.lastIndexOf('.'));
```
这样 root path 也能正确解析为 `.html` → `text/html; charset=utf-8`。

## Bug 修复 (2026-08-29 12:00)

### 问题 1: 发卡显示成功但实际未创建
**根因**: `POST /api/cards/issue` 要求用户已有借记卡才能付费（发卡费 245 CHF / 300 USD），新用户没有卡，导致循环依赖。
**修复**: 检测是否是第一张借记卡，如果是则免费创建。
```javascript
const existingDebit = await db.prepare(`SELECT COUNT(*) as cnt FROM cards WHERE account_id = ? AND type = 'debit'`).bind(acc.id).first();
const isFirstDebit = (existingDebit.cnt || 0) === 0;
const issueFee = isFirstDebit ? 0 : (issueBase === 'USD' ? 300 : 245);
```

### 问题 2: 卡片背面渲染错位
**根因**: `.card-back` 覆盖 `.card-front, .card-back` 的 `padding: 22px 24px`，设为 `padding: 0`，导致背面内容紧贴边缘。
**修复**: 将 `.card-back` 的 padding 改为 `22px 24px`，与正面保持一致。
