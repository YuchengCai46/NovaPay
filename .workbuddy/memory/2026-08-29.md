# 2026-08-29 工作日志

## Worker 部署修复

### 问题诊断
- Cloudflare Worker D1 异步复制问题：注册成功后立即登录，查询用户返回 "Account not found"
- 根本原因：D1 写入操作和读取操作可能路由到不同的副本节点，存在复制延迟

### 修复措施
1. **添加 `queryUserByEmailWithRetry` 函数** (`cloudflare/db.js`)
   - 指数退避重试（100ms → 200ms → 400ms → 800ms）
   - 最多 5 次重试
   - 适用于注册后立即登录的场景

2. **修复 worker.js 导入**
   - 在 `authLogin` 中使用重试函数
   - 添加 `queryUserByEmailWithRetry` 导入

3. **部署状态**
   - Worker 版本：`17562c5`
   - 部署成功：`https://novapay-api.caiyucheng32.workers.dev`
   - GitHub 仓库：`https://github.com/YuchengCai46/NovaPay`

### 已知限制
- D1 异步复制是 Cloudflare 的根本限制，重试只能提高成功率，无法完全消除
- 最佳实践：注册后立即使用注册返回的 JWT，避免二次登录请求

### 前端流程
- 注册后自动登录（`doRegister` 第 345 行），使用注册时返回的 JWT
- 登录功能对已存在用户有效（注册 5+ 秒后）
